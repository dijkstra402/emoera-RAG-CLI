Emoera Agent CLI 是 E时代 RAG 知识库的开源命令行客户端。它把文档、检索、问答、会话、模型与配额能力封装成稳定命令，并提供面向自动化的 JSON / JSONL 输出与退出码。

<CardGrid>
  <Card title="5 分钟开始" icon="ph:rocket-launch">安装 CLI、保存 Token，完成第一次知识库问答。</Card>
  <Card title="面向 Agent" icon="ph:robot">固定请求 ID、结构化输出、明确退出码与最小权限 Scope。</Card>
  <Card title="凭据不落盘" icon="ph:shield-check">桌面环境默认使用系统凭据库保存 Agent API Token。</Card>
  <Card title="可解释检索" icon="ph:magnifying-glass">查看召回文档、分数与内容，便于调试 RAG 质量。</Card>
</CardGrid>

## 推荐阅读顺序

<Steps>
  <Step title="安装">根据系统选择一键脚本、安装包或免安装压缩包。参见 <DocLink href="/zh/install">安装指南</DocLink>。</Step>
  <Step title="认证">在 E时代 RAG 个人中心创建 Agent API Token，并安全保存。参见 <DocLink href="/zh/authentication">认证与 Token</DocLink>。</Step>
  <Step title="第一次问答">初始化配置并运行 `emoera ask`。参见 <DocLink href="/zh/quickstart">快速开始</DocLink>。</Step>
  <Step title="接入 Agent">切换 JSON / JSONL 输出，并处理请求 ID 与退出码。参见 <DocLink href="/zh/automation">自动化与 Agent</DocLink>。</Step>
</Steps>

<Aside type="tip" title="开源仓库">CLI 使用 Apache-2.0 协议开源。源码、Issue 与 Release 位于 [dijkstra402/emoera-RAG-CLI](https://github.com/dijkstra402/emoera-RAG-CLI)。</Aside>
