<Steps>
  <Step title="创建 Agent API Token">登录 E时代 RAG，打开“个人中心 → Agent API”，创建具有所需 Scope 的 Token。完整 Token 仅显示一次。</Step>
  <Step title="初始化配置">

```bash
emoera config init
```

线上服务地址默认为 `https://rag.emoera.cn`。
  </Step>
  <Step title="安全保存 Token">

```bash
emoera auth set-token
```

按提示粘贴以 `em_sk_` 开头的 Token。
  </Step>
  <Step title="验证服务与身份">

```bash
emoera auth status
emoera whoami
emoera capabilities
```
  </Step>
  <Step title="选择默认模型">

```bash
emoera model list
emoera model use "Qwen3 8B"
emoera model current
```

这一步可跳过；未选择时使用服务端默认模型。
  </Step>
  <Step title="提出问题">

```bash
emoera ask "介绍一下知识库中的主要内容"
```
  </Step>
</Steps>

## 自建服务

```bash
emoera config set endpoint https://your-rag.example.com
```
