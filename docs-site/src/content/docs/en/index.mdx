Emoera Agent CLI is the open-source command-line client for Emoera RAG. It exposes document, retrieval, chat, session, model, and quota operations through stable commands with JSON/JSONL output and explicit exit codes.

<CardGrid>
  <Card title="Start in five minutes" icon="ph:rocket-launch">Install the CLI, save a token, and run your first knowledge-base query.</Card>
  <Card title="Agent-ready" icon="ph:robot">Stable request IDs, structured output, explicit exit codes, and least-privilege scopes.</Card>
  <Card title="Credentials stay protected" icon="ph:shield-check">Desktop tokens are stored in the operating system credential store.</Card>
  <Card title="Explainable retrieval" icon="ph:magnifying-glass">Inspect recalled documents, scores, and content when tuning RAG quality.</Card>
</CardGrid>

<Steps>
  <Step title="Install">Choose a one-line installer, native package, or portable archive in the <DocLink href="/en/install">installation guide</DocLink>.</Step>
  <Step title="Authenticate">Create an Agent API Token and save it securely. See <DocLink href="/en/authentication">authentication</DocLink>.</Step>
  <Step title="Ask a question">Initialize a profile and run `emoera ask`. See the <DocLink href="/en/quickstart">quickstart</DocLink>.</Step>
  <Step title="Automate">Adopt JSON/JSONL output, request IDs, and exit codes. See <DocLink href="/en/automation">automation and agents</DocLink>.</Step>
</Steps>
